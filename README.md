# Планирование работы персонала для магазина бытовой техники «Комп»

Система для планирования рабочего расписания сотрудников магазина бытовой техники «Комп» с учетом их пожеланий.

## Возможности

- Просмотр текущего расписания
- Указание желаемых выходных на следующую неделю
- Просмотр статистики отработанных смен по месяцам

## Технологии

- Python 3.12
- Django 5.2
- PostgreSQL
- Bootstrap 5
- Docker

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone git@github.com:Dialol/work_sheduler.git
cd work_sheduler
```

2. Создайте файл `.env` в корневой директории проекта со следующим содержимым:
```env
DEBUG=True
SECRET_KEY=your-secret-key-here
ALLOWED_HOSTS=localhost,127.0.0.1
DATABASE_URL=postgres://postgres:postgres@db:5432/work_schedule
```

3. Соберите и запустите контейнеры:
```bash
docker-compose up --build
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

# Алгоритм составления расписания

## Общее описание
Алгоритм создает еженедельное расписание для сотрудников магазина бытовой техники «Комп», учитывая:
- Требуемое количество сотрудников на каждый день недели
- Желаемые выходные дни сотрудников
- Равномерное распределение смен между сотрудниками

## Требования к расписанию
1. Количество сотрудников на каждый день:
   - Понедельник-пятница: 2 человека (один из них — директор)
   - Суббота: 1 человек
   - Воскресенье: выходной

2. Приоритеты при составлении:
   - Учет желаемых выходных дней сотрудников
   - Равномерное распределение смен
   - Минимальное отклонение от среднего количества смен
   - Обязательное присутствие директора в рабочие дни (пн-пт)

## Пример работы

Допустим, у нас 4 сотрудника: Директор (Николай), Продавцы: Мария, Елена, Алексей

### Понедельник (нужно 2 человека: директор + 1 продавец):
1. Директор работает обязательно
2. Мария и Алексей запросили выходной
3. Доступный продавец: Елена
4. Выбираем: Директор, Елена

### Вторник (нужно 2 человека: директор + 1 продавец):
1. Директор работает обязательно
2. Елена запросила выходной
3. Доступные продавцы: Мария, Алексей
4. У Марии и Алексея по 0 смен
5. Выбираем: Директор, Мария (по очереди)

### Суббота (нужен 1 продавец, директор может не работать):
1. Все продавцы доступны
2. У Марии — 2 смены, у Алексея — 1, у Елены — 2
3. Выбираем: Алексей (у него меньше всего смен)

И так далее...

## Проверка корректности
Алгоритм гарантирует:
1. Необходимое количество сотрудников на каждый день
2. Учет желаемых выходных (когда возможно)
3. Равномерное распределение смен (отклонение не более 1 от среднего)
4. Обязательное присутствие директора в рабочие дни (пн-пт)
5. Справедливый выбор при нехватке сотрудников

## Возможные улучшения
1. Добавить учет предыдущих смен (не ставить подряд)
2. Учитывать квалификацию сотрудников
3. Добавить возможность подмены при болезни
4. Учитывать пожелания по времени смен (для субботы)
